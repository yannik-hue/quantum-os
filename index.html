Install in 4 steps

  1. Download Rufus and write the ISO to a USB stick (8 GB or more). Choose "DD image mode" if Rufus asks.
  2. Restart the computer and boot from the stick (Boot Mode: Legacy/CSM, Secure Boot off).
  3. Set up your account on first start. Try the live system first.
  4. Open Install Quantum OS to install it on the disk. This erases the disk.

Updates

Installed systems update from Settings › Updates. No reinstall needed.
